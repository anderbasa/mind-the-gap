PART 1 — MULTIPLE-CHOICE CLOZE
- A text of 200–280 words with 8 gaps marked {1} to {8}, in order (no example gap).
- Each gap tests vocabulary: collocations, fixed phrases, phrasal verbs, linking words, dependent prepositions, idioms, or fine shades of meaning between near-synonyms.
- Four options A–D per gap, all of the same word class and superficially possible; only one fits because of collocation, meaning, or what follows (e.g. a dependent preposition or a complement pattern).
- The words right after (or before) the gap must rule out the distractors: e.g. a dependent preposition only one option takes, a fixed phrase only one option completes, or a meaning only one option has. Do NOT use four near-synonyms that all collocate with the next noun (e.g. foster / nurture / cultivate a sense of…).
- Vary the position of the correct letter across items.
- Set `focus` to what each item tests.
